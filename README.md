**Retail Sales & Customer Behaviour Analytics | SQL + Power BI**

📌 Project Overview

This project, Retail Analytics Case Study, focuses on analysing retail sales transactions, product performance, and customer purchasing behaviour to generate meaningful business insights.

The project follows an end-to-end data analytics approach, using MySQL for data cleaning, transformation, and advanced SQL analytics, followed by Power BI for interactive dashboard development and business performance reporting.

The dashboard provides insights into overall sales, customer activity, product performance, sales trends, and monthly growth.

🛠️ Tools & Technologies

MySQL: Data cleaning, data transformation, data validation, and advanced SQL analytics.

Power BI: Data modelling, KPI development, interactive visualizations, and dashboard reporting.

SQL: Joins, aggregations, CASE WHEN, CTEs, subqueries, and date-based analysis.

🗄️ SQL Analysis & Data Preparation

MySQL was used for data cleaning, transformation, and business analysis before developing the Power BI dashboard.

Data Preparation:

Identified and handled duplicate records.

Checked missing and NULL values.

Standardized data fields.

Corrected date formats and data types.

Validated transactional data.

Prepared datasets for analytical reporting.

Advanced SQL Analysis:

Joined customer, sales transaction, and product inventory tables.

Aggregated sales and purchase quantities.

Analysed customer transaction activity.

Calculated product and category-level sales.

Performed monthly and yearly sales analysis.

Used conditional aggregations and date functions.

Prepared analytical outputs for Power BI.
